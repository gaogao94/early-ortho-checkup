# 样例运行 · 康桥口腔门诊（全部数据为虚构）

> **本文件的所有机构名、人名、数字均为虚构，仅用于演示一次完整的体检运行。** 它同时是这份 skill 的自测样例：照着走一遍，可以验证一题一问、判分锚点、红线降级、优先序与"未知即结论"是否都能跑通。
>
> 这里的"运行"指一次 24 题的访谈 + 出报告。文中「助手」= 执行 SKILL.md 的 AI，「受访者」= 门诊负责人。为节省篇幅，访谈片段只摘录前 4 题，其余 20 题以判分账目形式给出。

## 场景

- 机构：康桥口腔门诊（虚构），3 名正畸医生 + 1 名医疗主管
- 受访者：老板兼医疗主管，姓周
- 数据自查：已用 `tools/early_ortho_metrics.py` 跑过一份导出 CSV（虚构）

## 第 1 轮 · 开场 + A1

**助手**

> 我们做一次早矫管理的体检：大概 15–25 分钟，我会一个问题一个问题地问，你按你现在的实际情况答就行，说不清的就说说不清——这本身就是有用的信息。
>
> 先说清边界：这套东西看的是管理，不做临床判断；结论只依据你说的，我不会替你补数。
>
> 第一个问题：现在你们在册的早矫病例一共多少例？其中有多少例已经超过当初计划的结束时间？

**受访者**

> 我得让前台导一下……在册 243 例。超期的没统计过，我印象里拖着的不少，具体多少说不上来。

**助手的账** `A1 | "在册 243 例；超期数没统计过，印象里不少" | 2 分 | 在册数能导出（2 档），超期数要临时统计；不是两个数都随手可查（不到 3 档）。按复合题取最低档的纪律，这一题记 2 分`

> R1 判据提示：SKILL.md 的 R1 是"A1 判 0 → 命中；判 1 → 信息不足；判 2/3 → 未命中"。这里判 2，**R1 未命中**；但超期数拿不到这件事要单列进 K2，并在报告里点出来。底数里缺的这一半，正是第 1–2 周要补的东西。

## 第 2 轮 · A2

**助手**

> 你们对早矫有明确的结束周期标准吗？比如一个病例计划多久结束、平均延期几个月算正常？

**受访者**

> 计划一般按 18 个月跟家长说。平均延期多少我们没算过，就有几个拖得特别久的，我记得得有三四个做了两年半以上。

**助手的账** `A2 | "计划一般按 18 个月跟家长说，平均延期没算过" | 1 分 | 锚点 1 档：口头有大概印象（18 个月），没有写下来，也没算过延期。2 档要求周期标准成文且统计过平均延期，不满足`

> R2 判据提示：SKILL.md 的 R2 是"A2 判 0/1，且到 A2 为止都拿不出任何可核的延期数字 → 命中；答完 A2 就判"。这里 A2 判 1，**R2 当场记命中**；后面问到 B5 时，受访者说的是"拆托槽就算结束"（终点定义），同样没有延期数，所以不改判。

## 第 3 轮 · A3

**助手**

> 什么样的孩子该做早矫、什么样的不该做、每次复诊要做什么、做到什么程度算结束——这些有没有写成文字？谁定的？谁在最终拍板？

**受访者**

> 没写成文字。基本都是我跟另外两个医生平时聊出来的共识，最后基本都是接诊的医生自己定，疑难的我看看。

**助手的账** `A3 | "没有文字标准，是平时的共识；基本接诊医生自己定，疑难的我看" | 1 分 | 有内部共识（1 档），无成文文件，拍板归经治医生；不满足 0 档"各按师承、无共识"，也不满足 2 档"有成文标准"`

## 计算过程（SKILL.md「评分规则」的实算）

单题合计（题号顺序 A1–A6 / B1–B6 / C1–C6 / D1–D6）：

| 维度 | 题号得分 | 合计 | 维度分 |
|---|---|---|---|
| A 标准与分级 | 2 1 1 1 1 1 | 7/18 | **39** |
| B 方案审核与闭环 | 1 1 1 0 1 1 | 5/18 | **28** |
| C 记录与过程数据 | 2 1 2 0 1 1 | 7/18 | **39** |
| D 财务与激励 | 1 0 1 0 1 0 | 3/18 | **17** |

总分 = (39 + 28 + 39 + 17) ÷ 4 = 123 ÷ 4 = **30.75 → 31**（四舍五入）。31 落在 31–55 区间，原始等级为 **L2 起步**。

红线判定（按 SKILL.md 的分档判据逐条判）：

| 红线 | 结论 | 依据 |
|---|---|---|
| R1 底数不清 | 未命中 | A1 判 2（在册数拿得到、超期数要临时统计）→ 按判据未命中；但缺的那一半要单列进 K2 |
| R2 无周期标准 | **命中** | A2 判 1（只有口头的 18 个月），答完 A2 就给不出可核的延期数字；后来 B5 也只能给出终点定义，同样没有延期数 |
| R3 结束无人核 | **命中** | B4 判 0：结束由经治医生口头判定，无书面复核 |
| R4 提成一次性发 | **命中** | D2 判 0：收款次月一次性发全额提成 |

命中 3 项 → **等级**封顶 L1（总分栏保持原分 31）。最终结论：**原分 31（L2 起步），因命中 R2、R3、R4 封顶至 L1 医生自治。**

> 这一例展示了降级规则的实际作用：单看分数是"起步"，看起来还行；但三条红线说明这台机器的控制点根本不在管理者手上——没有靶子、结束判不了、钱提前走完了。这正是文章讲的因果链。
>
> 另外注意 R1 与 R2 的差别：R1 只要"看没看见"（A1 判 0 才算命中），R2 要"有没有标准**并且**有没有数据"。这家机构在册数看得见，但周期标准与延期数据两头空，所以 R2 中、R1 不中。把两者混成一条，就会出现"分数很低但红线全灭"的误判。

### 动作优先序

红线与动作的挂钩：R2（A2、B5）→ ACT-1 与 ACT-2；R3（B4）→ ACT-2；R4（D2）→ ACT-5。所以本期的红线动作是 **ACT-1、ACT-2、ACT-5**。

先算每个动作"覆盖题号的平均得分"，并按阈值（均分 < 2，或覆盖题号里出现 0 分）判断是否算命中缺口：

| 动作 | 覆盖题号 | 均分 | 命中缺口？ |
|---|---|---|---|
| ACT-1 建标准、分级、看底数 | A1 2 A2 1 A3 1 A4 1 A5 1 A6 1 B1 1 B2 1 | **1.12** | 是（均分 < 2） |
| ACT-2 结果要核 | B4 0 B5 1 C4 0 D4 0 | **0.25** | 是（含 0 分） |
| ACT-3 阶段目标要跟 | B3 1 B6 1 C5 1 | **1.00** | 是（均分 < 2） |
| ACT-4 每次就诊都留痕 | C1 2 C2 1 C3 2 C6 1 | **1.50** | 是（均分 < 2） |
| ACT-5 提成按阶段发 | D2 0 D4 0 | **0.00** | 是（含 0 分） |
| ACT-6 财务的账要算明白 | D1 1 D3 1 D5 1 D6 0 | **0.75** | 是（含 0 分） |

六个动作全部命中缺口——这不是算法失灵，而是**这家机构确实处在起步阶段**：24 题里有 5 个 0 分，没有哪个管理面向是站得住的（三个 2 分分别是 A1、C1、C3，也就是"能查到"和"大部分留痕"这一点点基础）。等分数上来之后，阈值才会开始把动作筛掉。

再按三步排序（划范围 → 按均分升序 → 按档位重排；档位表见 SKILL.md，P0 在 P1 前、红线动作在非红线动作前，同档保持均分顺序）：

- 红线动作是 ACT-1、ACT-2、ACT-5。按 SKILL.md 的档位表：**ACT-1 与 ACT-2 属 P0**（导出底数表、改终点定义、立复核表，都在两周内且不动钱，所以两个都列在 P0），**ACT-5 属 P1**（要设计分期比例、公示规则、处理存量病例的过渡口径，以月计）。
- 非红线动作进最后一段，按均分升序：ACT-6（0.75）→ ACT-3（1.00）→ ACT-4（1.50）。

**最终优先序：ACT-2 (P0) → ACT-1 (P0) → ACT-5 (P1) → ACT-6 → ACT-3 → ACT-4。**（P0 里 ACT-2 均分 0.25 低于 ACT-1 的 1.12，所以 ACT-2 排前。）

> 这里能看出两层排序各自的作用。**第一层让红线动作插队**：ACT-1 均分 1.12，却排在均分 0.75 的 ACT-6 之前——因为红线 R2 落在它身上。**第二层里均分开始说话**：ACT-4 均分 1.50 最高，排到最后。优先序反映的是风险与缺口，不是分数高低；如果只按分数排，就会把"提成一次性发完""周期标准与延期数据两头空"这类最致命的问题排到后面。
>
> 注：D4（结束质量与绩效挂钩）同时挂 ACT-2 与 ACT-5，这是有意的。它既是一道"要核"的题——不核就看不出质量差别；也是一道"钱跟着什么走"的题——不挂钩就没有改进动力。两道动作都能把它往前推，报告按命中的那个动作来引。

## 报告节选

### 一、一句话结论

**L1 医生自治**：这家门诊的早矫已经有 243 例在册体量，但没有任何环节留在管理者手上——没有周期标准与延期数据，病例结束由经治医生自己说了算，提成在收款次月就发完了。原分 31（L2 起步），因命中 R2、R3、R4 三条红线封顶至 L1。

### 二、四维得分

| 维度 | 得分 | 该维度最大的缺口 |
|---|---|---|
| A 标准与分级 | 39/100 | 没有成文的过程管理标准，难度与能力分级不存在，产能上限没量化 |
| B 方案审核与闭环 | 28/100 | 方案只口头过一眼，结束无复核，终点定在"拆托槽" |
| C 记录与过程数据 | 39/100 | 重启率与延期从未统计，椅位时长未进系统，计划外处理混在常规记录里 |
| D 财务与激励 | 17/100 | 提成一次性发完，绩效不挂结束质量，预收款全额计收入，算不出单例毛利 |
| **总分** | **31 → 封顶 L1** | 原分 31，因 R2、R3、R4 封顶 |

### 七、八个关键指标

| 指标 | 数值 | 说明 / 取证方式 |
|---|---|---|
| K1 在册病例数 | 243 | 前台导出，与病历系统对账一致；**仅此一半**——超期数仍缺 |
| K2 延期病例占比 | **未知** | 需先在系统里给每例填"计划结束日期"字段，再按 as-of 日期比对；这正是第 1–2 周要做的事 |
| K3 计划 vs 实际时长 | 计划 18 个月；已结案病例的实际均值 20.1 个月 | 由导出 CSV 计算；口径为**拆托槽日期**，与 K4 的口径必须一致 |
| K4 平均延期月数 | 在册未结案病例均值 **4.5 个月**；已结案病例均值 **2.1 个月**（= 20.1 − 18） | 两个数不是一个口径：前者含仍在拖的病例，所以更大。报告必须写明 population，否则会被当成算错 |
| K5 计划外复诊率 | **未知** | 记录未单列计划外处理；先在复诊记录里加标识字段，再统计 |
| K6 椅位时长 / 每例次数 | 每例均 20.8 次；椅位时长**未知** | 就诊次数来自系统；椅位时长在挂号本有原始记录但未录入，需补录或用现场计时抽样 |
| K7 重启率 / 二次治疗率 | **未知** | 系统无重启标识；医疗主管口径为历史 8 例，不可用；需在系统加标识后回填 |
| K8 单例就诊次单价 | 收入侧 1385 元/次；成本侧**未知** | 收入侧 = 单例收费均值 ÷ 就诊次数；成本侧缺椅位时长与病例级材料成本 |

> 两条口径提醒。
>
> **K3/K4 必须标 population。** "平均延期 4.5 个月"是在册未结案病例的口径，"已结案病例延期 2.1 个月"是另一个口径。两个数放在一起不矛盾，但只写一个数、不写口径，复算的人会以为算错了。
>
> **K3/K4 的终点口径本身也待改。** 这两个数现在是按"拆托槽 = 结束"算出来的，而 B5 说明这家机构自己也是这么理解的。一旦按文章给的终点定义（首次保持器复诊通过）改口径，延期统计会显著变难看——**这不是数据变坏了，是第一次看清。**
