# 早矫体检 · 题库（24 题）

题库是访谈的**唯一提问来源**。一题一问，按 A1→A6、B1→B6、C1→C6、D1→D6 顺序问。

## 交互形式：选项题，不是自由文本

**每一题都以选项呈现，让受访者选，不让他打字。** 唯一允许自由文本的只有机构名称、门店数这类**事实性信息**——它们没有可枚举的答案。

### 提问格式（照这个格式发给受访者）

```
【3/24】现在你们在册的早矫病例一共多少例？其中有多少例已经超过当初计划的结束时间？

1. 随时能调出两个数，还能按医生、按门店分开看
2. 两个数都能查出来，但需要临时统计，花半天到一天
3. 只有一个数拿得到，另一个查不到
4. 两个都说不清，要靠问医生、翻本子
5. 不知道 / 没想过

回复数字即可。
```

四条纪律：

1. **不暴露分数。** 选项只写 `1. 2. 3. 4.`，**绝不写** `0 分/3 分` 或 `档位 0`。分数是内部映射（选项 1 → 3 分，选项 4 → 0 分，选项 5 → 0 分），受访者看到分数就会去猜"哪个分数高"，答案立刻失真。
2. **一次只发一题。** 发完停下等回复，不预告下一题的内容或方向。
3. **选项顺序固定**：从"没有/最原始"排到"最完备"，再接"不知道 / 没想过"。四题档位一一对应，不要为了好看打乱顺序——打乱了打分就会错。
4. **受访者不按选项答**（回了自由文本、答了题外话、只回一个"嗯"）：**把它归到最接近的那个选项**，念给受访者确认（"那这个我记成第 3 项，对吗？"），不要自己另起一个新的判断。

### 追问也必须是选项

有些题要看"他是真知道还是随口说"，这时追问**同一题**（追问不算新题），但追问同样给选项：

```
补充问一下：「18 个月」这个数是算出来的，还是大概估的？

1. 有测算依据，能说出怎么来的
2. 是经验估算，没有测算过程
3. 说不好
```

**追问只在必要时发**，一题最多追一次。受访者已经答得很具体（比如直接报了数字和来源）就不要追。

### 每题的结构

- **问**：念给受访者听的话。
- **选项**：四个档位 + 「不知道 / 没想过」。**顺序与分值固定**，见下表。
- **追问**：可选，同样带选项。
- **判分锚点**：只给助手看，用来把选项映射回 0–3 分。

**分值映射（唯一口径）**

| 显示顺序 | 含义 | 分值 |
|---|---|---|
| 选项 1 | 最完备 | **3** |
| 选项 2 | 部分到位 | **2** |
| 选项 3 | 零散 / 靠人 | **1** |
| 选项 4 | 没有 | **0** |
| 选项 5 | 不知道 / 没想过 | **0** |

> 注意：选项是**从好到差**排的（1 最好），和分数高低相反。这是因为受访者读起来顺：先看到"标准做法长什么样"，再对照自己。打分时别搞反。

## A 维度 · 标准与分级（管"你有没有标准"）

### A1 · 在册病例底数

**问**：现在你们在册的早矫病例一共多少例？其中有多少例已经超过当初计划的结束时间？

**选项**

1. 随时能调出两个数，还能按医生、按门店分开看
2. 两个数都能查出来，但需要临时统计，花半天到一天
3. 只有一个数拿得到，另一个查不到
4. 两个都说不清，要靠问医生、翻本子
5. 不知道 / 没想过

**追问（当受访者给了具体数字时）**：「这个数是随时能看到的，还是要专门去数？」

1. 随时能看到
2. 要专门去数，数得出来
3. 数不出来，只有印象

**判分锚点**（选项 1–4 → 3/2/1/0，选项 5 → 0）
- `3` 两个数随时可调，能按医生、按门店下钻。
- `2` 两个数都能从系统或报表查出，但要临时统计，半天到一天。
- `1` 只有一个数拿得到；或两个数都只有印象没有系统来源；或都要临时叫人统计半天。
- `0` 说不清在册数，也说不清超期数。
- **红线 R1**：判 0 或 1 → 命中。

### A2 · 计划周期标准

**问**：你们对早矫有明确的结束周期标准吗？比如一个病例计划多久结束、平均延期几个月算正常？

**选项**

1. 有分类型的周期标准，延期被持续统计，并进入医生反馈与排程
2. 有书面周期标准，也统计过平均延期，但没和医生考核或排程挂钩
3. 口头上有大概印象，但没有写下来，也没算过延期
4. 没有周期标准，也从未算过延期情况
5. 不知道 / 没想过

**追问**：「平均延期几个月」这个数是算出来的，还是估的？

1. 算出来的，有测算依据
2. 是经验估算，没有测算过程
3. 说不好

**判分锚点**
- `3` 分类型周期标准 + 延期持续统计 + 进入医生反馈与排程。
- `2` 有书面周期标准，统计过平均延期，未挂考核或排程。
- `1` 只有口头印象（"一年半到两年吧"），没写下来、没算过。
- `0` 没有周期标准，也从未算过延期。
- **红线 R2**：判 0 或 1，且答完 A2 仍拿不出任何可核的延期数字 → 命中。答完 A2 就判，不必等后面的题；后来 B5 若给出可核数字，回来改判未命中。

### A3 · 过程管理标准文本

**问**：什么样的孩子该做早矫、什么样的不该做、每次复诊要做什么、做到什么程度算结束——这些有没有写成文字？谁定的？谁在最终拍板？

**选项**

1. 标准成文、有版本、有明确的审核与更新机制，拍板人和依据都能说清
2. 有相对完整的成文标准，但审核、更新与拍板仍主要靠个别资深医生的经验
3. 有零散的内部共识或口头规矩，但没有成文文件
4. 没有成文标准，各医生各按自己师承的路子做，拍板就是经治医生本人
5. 不知道 / 没想过

**追问**：这些标准是谁定的？

1. 有明文规定的责任人或小组
2. 某位资深医生定的，没有明文
3. 没人专门定，各做各的

**判分锚点**
- `3` 成文、有版本、有审核更新机制、拍板有依据。
- `2` 成文较完整，但审核与拍板靠个别资深医生。
- `1` 零散共识或口头规矩，无成文。
- `0` 无成文标准，各按师承，经治医生自己拍板。
- **红线 R1 相关**：A3 判 0 也要在报告里点出"标准归属不明"。

### A4 · 病例难度分级

**问**：你们的病例有做难度分级吗？哪个级别对应哪个医生接手，有没有明文规定？

**选项**

1. 分级标准成文，明确"什么级别的医生接什么难度的病例"，并实际用于接诊分配
2. 有难度分类或分级表，但接诊分配仍按资历、排班或业绩临时决定
3. 医生心里大概有数，但没写下来，接诊主要看谁有空
4. 没有难度分级，来什么接什么
5. 不知道 / 没想过

**追问**：分级表实际用吗？

1. 接诊时按它分
2. 有表，但实际不全按它分
3. 有表基本没用

**判分锚点**
- `3` 成文 + 明确医患匹配 + 实际用于分配。
- `2` 有分级表，分配仍临时决定。
- `1` 心里有数，没写下来。
- `0` 无分级，来什么接什么。

### A5 · 医生能力分级

**问**：医生的能力有分级吗？谁有能力独立做哪个级别的早矫病例，这一条是怎么确定的？

**选项**

1. 能力分级有客观依据（完成病例数、结束质量、并发症等），定期复评、与接诊权限绑定
2. 有书面能力分级标准，但没有用病例记录、结束质量等客观数据支撑
3. 分级存在于管理者印象里，谁强谁弱靠感觉与年头
4. 没有能力分级概念，默认所有正畸医生都能做早矫
5. 不知道 / 没想过

**追问**：能力分级多久复核一次？

1. 定期复评，有记录
2. 想起来才看，没固定周期
3. 定过一次，之后没动过

**判分锚点**
- `3` 客观依据 + 定期复评 + 绑定接诊权限。
- `2` 有书面标准，无客观数据支撑。
- `1` 只在印象里，靠感觉与年头。
- `0` 没有能力分级概念。

### A6 · 承接容量约束

**问**：如果这个月一下子进来 30 个早矫病例，你们会怎么处理？有没有一个"不能再接了"的线？

**选项**

1. 有量化产能上限并执行，接诊节奏与复诊承载、医生能力匹配；超出时会排队或转诊
2. 有粗略的产能量化（比如每医生在册上限、每周复诊承载量），但不严格执行
3. 知道会吃不消，但没有量化过产能上限，靠临时加号、加班硬扛
4. 没有上限概念，来多少接多少，产能不是接诊的考虑因素
5. 不知道 / 没想过

**判分锚点**
- `3` 量化上限 + 执行 + 超出时排队或转诊。
- `2` 有粗略量化，不严格执行。
- `1` 知道会吃不消，没量化，硬扛。
- `0` 没有上限概念。

## B 维度 · 方案审核与结案（管"有没有人核"）

### B1 · 初诊方案审核

**问**：一个新病例开始之前，方案有审核环节吗？谁来审？审完会留什么书面记录？

**选项**

1. 全部新病例都要过审，审核意见书面上留痕、可追溯
2. 有书面审核环节，但只覆盖部分病例（比如只审疑难、只审新医生）
3. 有口头沟通或非正式招呼，但没有审核记录
4. 没有审核环节，医生定完就直接开始，无记录
5. 不知道 / 没想过

**追问**：审核的结果留在哪里？

1. 系统或纸质审核单，能查到
2. 有签字，但没有审核意见内容
3. 没有留下记录

**判分锚点**
- `3` 全覆盖 + 书面留痕可追溯。
- `2` 有审核，只覆盖部分病例。
- `1` 口头沟通，无记录。
- `0` 无审核环节。

### B2 · 审核内容的完整度

**问**：方案审核的时候，你们具体看哪几项？诊断依据、治疗目标、计划做多久——这三项在你们的审核表里都有吗？

**选项**

1. 审核表固定包含诊断依据、治疗目标、计划结束时长，三项都留有书面结论
2. 三项都有要求，但执行不一致，记录简略
3. 会看诊断，但目标与计划时长不固定，取决于审核人的习惯
4. 没有审核，或审核只是签字走流程
5. 不知道 / 没想过

**判分锚点**
- `3` 三项固定入表 + 都有书面结论。
- `2` 三项有要求，执行不一致。
- `1` 只看诊断，目标与时长随审核人。
- `0` 无审核或只签字。

### B3 · 阶段性目标

**问**：定方案的时候，会不会把中间的阶段性目标也写下来？比如每隔两三个月该达到什么状态？

**选项**

1. 方案固定含按时间（如每 2–3 个月）分解的阶段目标，且后续复诊对照执行
2. 要求设置阶段目标，但多数病例记录粗略，或只在疑难病例上做
3. 有阶段目标的意识，偶有记录，但没有固定时间间隔要求
4. 完全没有阶段目标，只写最终目标，中途靠医生自己把握
5. 不知道 / 没想过

**判分锚点**
- `3` 固定按时间分解 + 复诊对照执行。
- `2` 有要求，记录粗略或只做疑难。
- `1` 有意识，偶有记录，无固定间隔。
- `0` 只写最终目标。

### B4 · 结束复核

**问**：病例结束时，有没有一个独立的复核环节，对照当初定的目标逐条核对？复核不通过会怎样？

**选项**

1. 结束必须书面复核，对照初始方案逐条打勾，不通过则明确继续治疗或整改
2. 有复核动作，但对照的是大体效果，不是当初方案里的逐条目标
3. 有口头过问或上级医生随口确认，没有对照目标的核对
4. 没有复核，经治医生说结束就结束
5. 不知道 / 没想过

**追问**：复核结果进不进绩效？

1. 进，和结算挂钩
2. 会记录，但不影响收入
3. 不记录，也不影响

**判分锚点**
- `3` 书面复核 + 对照初始方案逐条 + 不通过有明确处置。
- `2` 有复核，对照大体效果。
- `1` 口头过问，无对照。
- `0` 没有复核。
- **红线 R3**：判 0 或 1 → 命中。

### B5 · 治疗终点定义

**问**：你们认为一个病例做到哪一步算"结束"？是拆托槽那天，还是保持器复查通过之后？

**选项**

1. 明确定义首次保持器复诊为终点，并在系统状态、统计口径、绩效结算上一致执行
2. 知道要保持器复查才算完，但系统状态与统计仍按拆托槽结算与结案
3. 默认"拆托槽"就是结束，保持器阶段不算在管理范围内
4. 没有终点定义，凭感觉
5. 不知道 / 没想过

**判分锚点**
- `3` 首次保持器复诊为终点 + 三处口径一致。
- `2` 知道，但系统与统计仍按拆托槽。
- `1` 默认拆托槽即结束。
- `0` 没有终点定义。

### B6 · 偏离处理机制

**问**：一个病例做到一半，发现进度比计划慢了、或者效果不如预期，你们有一套处理流程吗？谁来定"要不要改方案"？

**选项**

1. 偏离有明确触发条件，必须记录并复核，改方案要留痕、要重新确认时间节点
2. 有处理流程（讨论、会诊、调整方案），但触发与否取决于医生主动上报
3. 医生会口头说明，但没有记录，也没有统一的触发条件
4. 没有处理流程，医生自己决定，管理者通常不知道
5. 不知道 / 没想过

**判分锚点**
- `3` 明确触发条件 + 记录复核 + 改方案留痕并重定节点。
- `2` 有流程，靠医生主动上报。
- `1` 口头说明，无记录无触发条件。
- `0` 无流程，管理者不知情。

## C 维度 · 记录与过程数据（管"看不看得见"）

### C1 · 就诊留痕纪律

**问**：早矫复诊的时候，是不是每一次就诊都挂号、都写病历？有没有那种"简单处理一下、不上牙椅"就不挂号的情况？

**选项**

1. 全部就诊留痕，且有核查机制（抽查、系统校验）保证执行
2. 有"每次就诊都要留痕"的明确要求，但执行有漏洞，无人核查
3. 有时挂号有时不挂，取决于当班前台或医生习惯，没有明确要求
4. 计划外复诊基本不挂号、不写病历，属于普遍现象
5. 不知道 / 没想过

**判分锚点**
- `3` 全部留痕 + 有核查机制。
- `2` 有要求，执行有漏洞，无人核查。
- `1` 看人，没有明确要求。
- `0` 计划外普遍不留痕。

### C2 · 记录内容字段

**问**：一次复诊记录里会写哪些内容？托槽掉了来粘、钢丝扎嘴来复查这类计划外的处理，会单独记录吗？

**选项**

1. 结构化记录 + 计划外处理单列标识，可直接统计每例的计划外复诊次数
2. 有结构化记录（主诉、处理、下一步），计划外处理能在记录里看出来
3. 有记录，但内容随意，计划外处理混在常规复诊里
4. 记录只有一两句模糊描述，或干脆不记录
5. 不知道 / 没想过

**判分锚点**
- `3` 结构化 + 计划外单列标识，可统计。
- `2` 结构化，能看出计划外。
- `1` 记录随意，混在一起。
- `0` 模糊描述或不记录。

### C3 · 效率指标入报表

**问**：你们现在的报表里，能看到每一个早矫病例来了多少次、平均占了多久牙椅、重启过几次吗？

**选项**

1. 三个指标都在常规报表里，可按医生、按病例类型下钻
2. 报表能看到部分指标（比如就诊次数），但椅位时长或重启次数仍缺
3. 能零散查到，但要人工翻记录、逐例算，不是常规报表
4. 报表只有收入和成交，看不到就诊次数与椅位时长
5. 不知道 / 没想过

**追问**：椅位时长是怎么记的？

1. 系统自动记，有进出时间
2. 挂号本上有，但没录入系统
3. 没有记录

**判分锚点**
- `3` 三项都在常规报表，可下钻。
- `2` 能看到部分，缺一两项。
- `1` 要人工翻查，非常规报表。
- `0` 只有收入成交。

### C4 · 重启与延期统计

**问**：重启率、延期月数这两个数，你们有在统计吗？是按月/按季度看，还是从来没人算过？

**选项**

1. 两者按周期统计，进入管理复盘，并与医生反馈、方案审核挂钩
2. 有统计，但不是周期性看，或者只用来看个别医生
3. 偶尔被提起（比如质控会上口头提一句），但从不形成数据
4. 两个数都没统计过，也没有这个概念
5. 不知道 / 没想过

**判分锚点**
- `3` 按周期统计 + 进复盘 + 挂医生反馈与方案审核。
- `2` 有统计，非周期或只对个别人。
- `1` 口头提起，无数据。
- `0` 都没统计。

### C5 · 进度地图使用

**问**：每次复诊的时候，医生会不会把当初的方案和进度拿出来，跟家长对一对"走到哪一步了、下一步做什么"？

**选项**

1. 每次复诊都对照阶段目标与家长确认进度，变化有记录
2. 有对照进度的要求，但执行看医生个人，也没有对家长的书面留痕
3. 偶尔会和家长沟通进度，但没有固定的对照动作
4. 方案只在治疗开始前用一次，之后基本不再翻
5. 不知道 / 没想过

**判分锚点**
- `3` 每次复诊对照 + 与家长确认 + 变化有记录。
- `2` 有要求，执行看人，无书面留痕。
- `1` 偶尔沟通，无固定动作。
- `0` 方案只用一次。

### C6 · 成本归属到病例

**问**：矫正用到的耗材和加工件（比如矫治器、托槽），做出入库吗？能不能算到具体某一个病例和某一个医生头上？

**选项**

1. 耗材与加工件都做出入库，且精确归属到病例与医生，可算单例材料成本
2. 能归到医生，但归不到具体病例
3. 有出入库记录，但只到门店或科室层级
4. 没有出入库，耗材按整体采购支出粗略看，归不到病例
5. 不知道 / 没想过

**判分锚点**
- `3` 出入库 + 精确归属到病例与医生。
- `2` 能归医生，归不到病例。
- `1` 只到门店或科室。
- `0` 无出入库。

## D 维度 · 财务与激励（管"账明不明白"）

### D1 · 预收款确认规则

**问**：家长一次性交的整个疗程费用，你们在财务上是怎么确认收入的？是收款当月全额算营收，还是按服务进度分期确认？

**选项**

1. 有明确的收入确认规则（书面、符合会计准则与法规），报表上能看出预收款负债余额
2. 有分期确认的做法，但规则不成文，或与提成、报表口径不一致
3. 知道全额确认不妥，但"一直这么算"，没有明确规则
4. 收款当月全额计入营收，没有预收款或合同负债概念
5. 不知道 / 没想过

**判分锚点**
- `3` 成文规则 + 报表能看出预收款负债余额。
- `2` 有分期做法，不成文或口径不一致。
- `1` 知道不妥，一直这么算。
- `0` 全额计营收，无负债概念。

### D2 · 提成发放节奏

**问**：矫正病例的提成是什么时候发的？收款次月就一次性发完，还是分几次发？

**选项**

1. 按阶段发放并与质控绑定：收款发一部分、中期发一部分、病例结束且质控合格发尾款
2. 有分期发放规则，但分期依据含糊（比如按时间发，不按节点），或执行不完全
3. 有少量预留或口头约定，但没有成文规则，也不与质控结果挂钩
4. 收款当月或次月一次性发放全额提成，与病例进度、结束质量无关
5. 不知道 / 没想过

**追问**：分期的节点是怎么定的？

1. 按病例节点定（比如中期、结束）
2. 按时间定（比如每月发一次）
3. 没有明确节点

**判分锚点**
- `3` 按阶段发 + 与质控绑定 + 尾款挂结束质量。
- `2` 有分期，依据含糊或执行不完全。
- `1` 少量预留或口头约定，不成文。
- `0` 一次发完。
- **红线 R4**：判 0 → 命中。

### D3 · 负债与产能匹配

**问**：你们老板（或你）每个月会看两个数的对比吗——手上还没交付的预收款余额（欠家长的服务）和医生的交付能力？

**选项**

1. 每月对账：未交付预收款余额 vs 在册病例所需交付工时/产能，并据此调整接诊与排程
2. 有预收款余额或类似口径的数据，但没有和产能、排程放在一起看
3. 心里知道欠着服务，但没有量化过，也没有月度对比
4. 只看现金流和营业额，没有未交付服务的概念
5. 不知道 / 没想过

**判分锚点**
- `3` 每月对账 + 据此调整接诊排程。
- `2` 有余额数据，未与产能并看。
- `1` 心里知道，没量化。
- `0` 只看现金流营业额。

### D4 · 结束质量与绩效挂钩

**问**：医生的绩效里，有没有和"按期结束、结束质量"挂钩的部分？还是只跟接了多少病例、收了多少钱挂钩？

**选项**

1. 绩效明确含按期完成率、结束质量（脱矿率、新发龋率等）与复诊复核结果，权重可观
2. 绩效里有结束质量项，但权重低或指标粗糙（比如只看是否结束）
3. 有质量考核，但只是口头要求，不进薪酬
4. 绩效只跟新接病例数和收入挂钩，结束快慢与质量不影响收入
5. 不知道 / 没想过

**追问**：结束质量在绩效里大概占多少？

1. 能说清比例，且不算小
2. 很小，象征性的
3. 说不好

**判分锚点**
- `3` 明确含按期完成率 + 结束质量指标 + 权重可观。
- `2` 有结束质量项，权重低或指标粗。
- `1` 口头要求，不进薪酬。
- `0` 只挂新接数与收入。

### D5 · 单例毛利核算

**问**：把一个早矫病例从头做到尾，能赚多少——这个数你们算得出来吗？算的时候把复诊人工、椅位占用、耗材和加工件都算进去了吗？

**选项**

1. 单例毛利可核算，含就诊次数、椅位时长、耗材加工件与计划外复诊，并能横向对比其他项目
2. 算得出单例毛利，但依赖人工估算，且不含计划外复诊带来的成本
3. 有粗略估算（用收费减材料费那种算法），不含人工与椅位
4. 只知道收费价格，从没算过单例成本与毛利
5. 不知道 / 没想过

**判分锚点**
- `3` 可核算 + 含四项成本 + 可横向对比。
- `2` 算得出，靠人工估算，不含计划外。
- `1` 粗略估算，不含人工与椅位。
- `0` 只知道收费价格。

### D6 · 就诊次单价

**问**：单例收费除以就诊次数——也就是一次就诊大概摊到多少收入——这个数你们有吗？成本侧算过吗？

**选项**

1. 收入侧与成本侧都算得出，能看到延期如何摊薄单次单价，并用于项目决策
2. 算得出收入侧的单次单价，成本侧仍靠估算
3. 觉得有意义，但没算过；或只有收入侧，没有成本侧
4. 没有这个数，也没听说过这种算法
5. 不知道 / 没想过

**判分锚点**
- `3` 收入侧与成本侧都算得出 + 用于项目决策。
- `2` 收入侧算得出，成本侧估算。
- `1` 没算过，或只有收入侧。
- `0` 没这个数。
