## 0. 怎么用

1. 先判体裁与读者。报告是给诊所老板/合伙人看的经营自查报告，不是散文、不是公文。**不因此强加"我/你"，也不拆成短段落**（去AI味 SKILL.md 开篇与「不改的情况」）。

4. 交付前过 §8 验收清单；对某处是否命中没有把握 → **保持原文**。

## 1. 适用边界：什么能动，什么一个字都不能动

### 1.1 证据层（逐字保留，任何规则都不覆盖）

| 类别 | 报告里的实例 | 为什么不能动 |
|---|---|---|
| 判决与等级 | `R2 命中`、`未命中`、`L1`、`封顶`、`不知道` | 判决是产品结论，改写即篡改 |
| 分数 | `原分 31`、`39/100`、`warn 2/3`、`0 档` | 复算依据 |
| 题号与编号 | `A1–D6`、`R1–R4`、`ACT-1–ACT-6`、`K1–K8`、`L1–L4`、`P0–P2` | 接口契约，见 §4.1 |
| 受访者原话 | `在册 243 例；超期数没统计过，印象里不少` | 证据。含口语、错别字、里面的"大概"等词表命中词，都不动 |
| 判分依据 | `在册数能导出，超期数要临时统计`、`（2 档）` | 必须与分数一致 |
| 数据与统计口径 | `243`、`20.1 个月`、`4.5 个月`、`1385 元/次`、`口径为拆托槽日期` | 数字是结论的骨头 |
| 未知与取证方式 | `未知`、`需先在系统里给每例填「计划结束日期」` | "未知即结论"，报告第七节 |
| 结构与位置 | 八个部分、表格列、列表层级与顺序 | 文章结构不在处理范围 |

**对账办法**（去AI味 SKILL.md「信息守恒」）：改写后每个实词都要能在原文或 `report.json` 字段里指出出处。指不出来就是新增，必须撤销。

### 1.2 不许新增
姓名、机构名、职务、地名；数字、比例、金额、时长、次数；日期与先后顺序；引语；引用来源；因果、动机、心理活动；原文没写的细节、场景、案例。也不许把"把抽象写具体"当成本规范的任务。

### 1.3 不许删减
观点、结论、**限定词与让步**（"可能""通常""据说""预计"）全部保留。把"预计两周"改成"两周"是篡改强度，不是去 AI 味。

### 1.4 不确定就保留
对某处是否命中规则没有把握时，保持原文。这条优先于"读起来更顺"。

## 3. 不作为改写理由（不要过度改）

以下是 SKILL.md 明确列为**硬约束**的"不能据此改文字"清单，本报告的具体实例一并列出：

| 看着像 AI 味 | 为什么不改 | 本报告实例 |
|---|---|---|
| 句长、段长不参差 | 实测与人类写作无差别 | 不要为了"节奏"拆短报告的段落 |
| 被动句、名词化、长句 | 现代汉语书面语的正常写法 | `病例结束由经治医生自己说了算`、`复核结果进入医生绩效` |
| 正文里的"首先……其次" | 与人类无差别（第 6 条只管小标题编号） | 报告用 `1. 2. 3.` 有序列表，不是这条 |
| 句内同构排比 | 人类用得不比 AI 少 | `结束由经治医生口头判定；终点定在拆托槽；重启率与延期从未统计；绩效不挂结束质量` ← **保留** |
| 正文问句、设问 | 人类远多于 AI，删掉更不像人写 | `这一单赚不赚钱、和别的项目比怎么样` |
| 比喻本身 | 人类用得比 AI 多 | 报告里没有 |
| 顿号三项以上但属清单/契约 | 规则 2 的"不改" | 复核四项、动作名 |

## 5. 可读性专章（用户明确要求，不属于去 AI 味规则）

用户原话：

> 括号很多，以及类似括号的表述很多，冒号也很多。还有就是，有些词儿我觉得人很难理解，比如说，什么叫运转中，就这种就不太能理解。

SKILL.md 没有一条规则对应这三类问题，所以单列。执行时同样受 §1 的信息守恒约束：**只换说法、并句、去冗余，不新增事实。**

### 5.1 括号与插入语过多

实测（先剥掉 Markdown 装饰再计数）：

| 指标 | 旧稿 | 新稿 | 人类文章 |
|---|---|---|---|
| 全角括号（） | 44 处（14.9/千汉字） | 31 处（10.2/千汉字） | 2 处（0.7/千汉字） |
| 直角引号「」 | 13 处 | 12 处 | 0 处 |
| 中文冒号： | 58 处（19.6/千汉字） | 23 处（7.6/千汉字） | 3 处（1.1/千汉字） |

新稿 31 处括号中，**24 处是逐题明细"判分依据"列的 `（N 档）`**（另 1 处是 `（含简单处理）`）。它与同一行"判分"列的 `2/3` 完全重复（0 档 = 0 分、1 档 = 1 分，分数与档位一一对应），**删掉不丢信息**——这是单项收益最大的一处修改。

| 括号类型 | 实例 | 处置 |
|---|---|---|
| 结构性短标注 | `（2 档）`、`（L1 档）` | 删（信息已在判分/得分列）；要留就并入该列 |
| 补充说明 | `（243 例在册病例表的算术汇总）`、`（同时补齐 K1 缺的另一半）`、`（例如不低于三成）`、`（四个维度的平均是 31）` | 并进句子：改逗号或独立短句 |
| 说明性表头 | `依据（题号 + 受访者原话）` | 表头可留 |
| 系统取值/字段的引号 | `「拆托槽」`、`「首次保持器复诊通过」`、`「计划结束日期」`、`「未知」` | 保留（引号标出的是系统里的确切取值） |
| 普通短语被加引号 | `「谁能接什么」` | **去掉引号** |
| 方括号编号 | 旧稿 `【P0】` | 新稿已改成 `· P0 ·`（对） |

三条原则：
1. 括号里是事实或数字 → 并进句子，不要塞括号。
2. 括号里是重复信息（档位 vs 分数）→ 删括号，改成表格列。
3. `「」` 只用于两种情况：引用（受访者原话）、系统字段或状态的确切取值（首次出现）。

### 9.4 为什么这三个脚本不能当单篇报告的 lint

上面三张表几乎全是 0.00，但旧稿明明有 24 处提示语冒号、8 处序数词小标题。原因是：

1. **词表不覆盖报告的真实毛病。** `[基准]提示性冒号` 的词表是"一句话总结/结论/核心是/关键在于……"，**没有** `现状` `要做的事` `验收标准` `预计见效时间` `做到这一步算完成` → 旧稿 24 处、规范判定必改的冒号，脚本测出 0.00。
2. **`[基准]段首序数词` 只认"首先/其次/第一/第二"，不认「一、二、三」。** 旧稿 8 处 `## 一、`…`## 八、` 测出 0.00；反而是人类文章里的 4 处被算成 1.49/千字。
3. **分母是语料汉字数**，单篇 3000 字里一处命中就是 0.33/千字。新稿 1 处破折号 → 0.33，人类文章 2 处 → 0.75，于是"人类更多"——两边各一两处，纯噪声。`inf×` 是分母近零的除零保护，不是"AI 是人类无穷倍"。
4. **只给频率，不给位置。** 三个脚本都不输出行号，无法用来改稿。
5. **部分标记与 SKILL.md 相反。** `MARKERS` 里的"复数硬译""被动-抽象""以一种…方式""扮演角色""使得…能够"，SKILL.md 明确说这些**不是** AI 味、不许据此改（翻译腔只保留五种）。照脚本改会破坏白名单原则。
6. **没有判定与门禁。** 无阈值参数，退出码恒 0，不能当 CI 检查。

**结论**：这三个脚本适合 ① 复核 `SKILL.md` 里的频率论断，② 在**几百篇的大语料**上比较人类/AI 差异。**不适合**当单篇报告的检查工具。

### 9.5 替代做法：单篇定位器

去 AI 味的规则都有可定位的触发标记，所以单篇检查要的是"逐句定位"，不是"每千字频率"。下面是本次实跑用的脚本（`%TEMP%\eoc_style_check\probe.py`，纯标准库，**原样贴出**；若搬进 `tools/`，建议改名 `check_report_tone.py`）：

```python
"""按去 AI 味规则逐条定位现有报告文案的命中位置（行号 + 原文）。

用法：
    python probe.py <文件.md> [更多文件...]

这是 writing-style.md 给出的「替代做法」：SKILL.md 的规则有触发标记、可逐句定位，
而三个语料统计脚本给的是全篇每千字频率，定位不到句子。
先把 Markdown 装饰（** ` | ）剥掉再匹配，否则「**现状**：」这类提示语冒号会被漏掉。
"""
import re
import sys
from pathlib import Path

LABEL_COLON = re.compile(r"^\s*(?:[-*>]\s*)?(现状|要做的事|验收标准|预计见效时间|结论|核心是|关键在于|原因如下|本质上|换句话说|一句话结论)\s*[：:]")
PROMPT_COLON = re.compile(r"(现状|要做的事|验收标准|预计见效时间|结论|核心是|关键在于|原因如下|本质上|换句话说)[：:]")
ORDINAL_HEAD = re.compile(r"^#{1,6}\s*(一|二|三|四|五|六|七|八|九|十)、")
REVERSAL = re.compile(r"(不是|并非|不在于)[^，。！？\n]{1,25}[，]?(而是|而在于|是)")
DASH = re.compile(r"——")
DUNHAO = re.compile(r"[^，。！？；：\n]{1,14}、[^，。！？；：\n]{1,14}、[^，。！？；：\n]{1,14}")
BANNED = re.compile(r"(说白了|说穿了|先说结论|只做一件事)")
ZERO_SUBJ = re.compile(r"^(听起来|看起来|说白了|值得注意的是|更重要的是|关键在于|问题在于|意味着|不难看出)")
PAREN = re.compile(r"（([^（）]{0,60})）")


def demd(line: str) -> str:
    """剥掉行内 Markdown 装饰，保留行号对应关系。"""
    s = line.replace("**", "").replace("`", "")
    if s.lstrip().startswith("|"):
        s = s.replace("|", " ")
    return s


def report(path):
    raw = Path(path).read_text(encoding="utf-8")
    lines = raw.split("\n")
    clean = [demd(x) for x in lines]
    text = "\n".join(clean)
    print(f"\n===== {path} =====")
    print(f"共 {len(lines)} 行，{len(re.findall(r'[一-鿿]', text))} 汉字")

    print("\n-- 标点计数（已剥掉 Markdown 装饰）--")
    for k, v in [
        ("全角括号（）", len(re.findall(r"（", text))),
        ("半角括号()", len(re.findall(r"\(", text))),
        ("中文冒号：", len(re.findall(r"：", text))),
        ("顿号、", len(re.findall(r"、", text))),
        ("破折号——", len(re.findall(r"——", text))),
        ("直角引号「」", len(re.findall(r"「", text))),
    ]:
        print(f"  {k:<12}{v:>4}   （每千汉字 {v / max(len(re.findall(r'[一-鿿]', text)), 1) * 1000:.1f}）")

    print("\n-- 逐条规则命中（行号: 原文）--")
    for name, rx in [
        ("规则5a 提示语冒号（行首标签式）", LABEL_COLON),
        ("规则5a 提示语冒号（任意位置）", PROMPT_COLON),
        ("规则6 序数词小标题", ORDINAL_HEAD),
        ("规则1 翻案腔", REVERSAL),
        ("规则4 破折号", DASH),
        ("规则2 顿号罗列过密", DUNHAO),
        ("规则9 禁用起手式", BANNED),
        ("规则11 段首零主语评论", ZERO_SUBJ),
    ]:
        hits = []
        for i, ln in enumerate(clean, 1):
            if ln.strip().startswith("```"):
                continue
            for m in rx.finditer(ln):
                hits.append((i, m.group(0)))
        print(f"\n[{name}] 命中 {len(hits)} 处")
        for i, s in hits[:14]:
            print(f"  L{i}: {s}")
        if len(hits) > 14:
            print(f"  …（共 {len(hits)} 处）")

    # 空转句：以冒号结尾，下一非空行是列表/编号
    spin = []
    for i, ln in enumerate(clean, 1):
        s = ln.strip()
        if not s.endswith(("：", ":")) or s.startswith("```"):
            continue
        nxt = next((x.strip() for x in clean[i:] if x.strip()), "")
        if re.match(r"^([-*]|\d+[.、])", nxt):
            spin.append((i, s))
    print(f"\n[规则5b 空转句引出列表] 命中 {len(spin)} 处")
    for i, s in spin[:14]:
        print(f"  L{i}: {s}")

    # 括号内容普查：长括号 = 该并进句子的插入语
    print("\n-- 括号内容普查（按内容长度降序，>=6 字的是插入语候选）--")
    ps = []
    for i, ln in enumerate(clean, 1):
        for m in PAREN.finditer(ln):
            ps.append((len(m.group(1)), i, m.group(1)))
    ps.sort(reverse=True)
    for n, i, c in ps[:24]:
        print(f"  L{i} [{n}字] （{c}）")
    print(f"  括号总数 {len(ps)}；其中内容 >=6 字的 {sum(1 for n, _, _ in ps if n >= 6)} 处")


if __name__ == "__main__":
    for p in sys.argv[1:]:
        report(p)
```
